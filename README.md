
# ✨ MotionUI Studio — Animated Creative Agency Website

A modern, responsive, and animated creative agency website built using HTML, CSS, and JavaScript. This project focuses on attractive UI/UX design, smooth animations, interactive elements, and a professional user experience.

## 🌟 Features

- 🎨 Modern dark theme with purple and blue gradients
- ✨ Animated hero section with floating shapes
- 📱 Fully responsive layout for desktop, tablet, and mobile
- 🧭 Responsive navigation menu for mobile devices
- 🌀 Smooth scrolling and scroll progress indicator
- 🎬 Scroll-triggered reveal animations
- 💳 Interactive service cards with hover effects
- 🖼️ Creative project portfolio with visual previews
- 📊 Animated statistics counter
- 📩 Contact form with client-side validation
- ♿ Keyboard focus indicators and reduced-motion support
- ⚡ Lightweight frontend with no JavaScript frameworks
- 🔤 Modern typography using Google Fonts

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, responsive layouts, gradients, transitions, and animations
- **JavaScript** — Navigation, scroll effects, animated counters, and form validation
- **Google Fonts** — Space Grotesk and DM Sans
- **Git & GitHub** — Version control and project hosting
- **GitHub Pages** — Static website deployment

## 🚀 Getting Started

### 1. Clone the Repository

Open Git Bash or your terminal and run:

```bash
git clone https://github.com/YOUR-USERNAME/motionui-studio.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the Project

```bash
cd motionui-studio
```

Open the folder in Visual Studio Code.

### 3. Run the Website

1. Open `index.html` in VS Code.
2. Install the Live Server extension if needed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. View the website in your browser.

You can also open `index.html` directly in a browser.

## 🌐 Deploy with GitHub Pages

1. Push your project files to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder.
6. Click **Save**.
7. Wait for deployment and open the published website URL.

## How to upload `README.md` to GitHub

1. Save the file in the same folder as `index.html`.
2. Open Git Bash in the `motionui-studio` folder.
3. Run these commands:

```bash
git add README.md
git commit -m "Add project README"
git push
```

After pushing, open your GitHub repository. The README will automatically appear on the repository's main page.

**Important:** Replace `YOUR-USERNAME` in the clone command with your actual GitHub username before using it.
